# ML Models Models for Complex Graphs

A module for integrating ML into the StructuralGT software.

We design and build reinforcement learning (RL) and convolution neural network (CNN) models, for complex graphs—specifically those generated using the Structural-GT software.

For full documentation visit [owuordickson.github.io/sgt-ml](http://owuordickson.github.io/sgtml)
