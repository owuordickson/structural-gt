# StructuralGT Documentation

StructuralGT is a powerful software tool designed for graph theory analysis of nanostructures. It is a modified version of the original StructuralGT proposed by Drew A. Vecchio.

## Installation Options

There are three ways to install StructuralGT:

### 1. Software Installation
- Download the software through the [official form](https://forms.gle/UtFfkGGqRoUjzeL47)
- Follow the installation wizard
- Watch the [5-minute tutorial](https://www.youtube.com/watch?v=bEXaIKnse3g) to get started

### 2. pip Installation
Requirements:
- Python 3.13
- pip package manager
